# 운영 룰

## 반드시 지킬 것
- 수산물은 전체 제외한다.
- DailyFood 판매 판단은 엑셀 기준 금지. 실제 사이트에 노출된 판매 상품 기준으로만 판단한다.
- 월억은 기존 전체 수집 방식으로 판단한다.
- 공급가 그대로 고객 가격에 노출 금지.
- 같은 상품군은 WooCommerce variable product 1개로 묶고, 규격/중량/수량은 옵션으로 만든다.
- 고객 화면에 supplier_id, supplier cost, source_product_id, source_option_id, source URL, 원본 URL 노출 금지.
- 이미지 크롤링/첨부 금지.
- 상세 설명은 텍스트만 수집한다.
- 주문/회원/일반 글/페이지/미디어 삭제 금지.
- secret, API key, 로그인 정보 출력 금지.

## 마진 규칙
- 10,000원 미만: 공급가 + 1,500원.
- 10,000원 이상 ~ 20,000원 미만: 공급가 + 2,000원.
- 20,000원 이상 ~ 30,000원 미만: 공급가 + 3,000원.
- 30,000원 이상: 공급가 + 4,000원.

## 상품 반영 원칙
- 두 공급처 중 판매 가능한 최저 공급가를 선택하고 마진을 더한다.
- 두 공급처 모두 미판매이면 hub에 생성하지 않는다.
- hub에 이미 있는데 두 공급처 모두 미판매이면 삭제 후보로 본다.
- 판단 애매하거나 크롤링 실패면 삭제하지 않는다.
- public 생성은 명시적으로 허용된 재구축 작업에서만 한다.
