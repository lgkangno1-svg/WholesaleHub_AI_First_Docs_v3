# 보고 기준

Codex 최종 보고는 짧고 숫자 중심으로 한다.

## 필수 항목
- 성공/실패.
- 변경한 상품 수.
- 삭제한 상품 수.
- 생성한 상품 수.
- 생성한 옵션 수.
- public 생성 수.
- 수산물 노출 수.
- 누락 상품 수.
- 마진 규칙 오류 수.
- QA 문제 수.
- n8n 활성화 여부.
- commit hash.

## 보고 금지/주의
- 불필요한 장문 설명 금지.
- secret, API key, 로그인 정보 출력 금지.
- 실행 로그 전체 덤프 금지.
- 실패 시에는 실패 원인과 다음 조치만 짧게 보고한다.
