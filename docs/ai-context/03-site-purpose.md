# 사이트 목적

도매허브는 DailyFood와 월억 상품을 WooCommerce에 자동 반영하는 운영형 쇼핑몰이다.

## 핵심 목적
- 공급처 최신 판매 상태, 가격, 옵션을 hub 상품에 반영한다.
- 같은 상품/같은 옵션은 고객에게 중복 노출되지 않게 하나의 hub variation으로 유지한다.
- 신규 옵션과 신규 상품을 공급처 기준으로 식별한다.
- 공급처별 주문/발주를 분리할 수 있게 내부 meta와 order item snapshot을 저장한다.
- 발주 엑셀을 자동 생성하고 필요 시 이메일로 전달한다.

## 화면 구조
- 고객에게는 일반 쇼핑몰처럼 보인다.
- 고객 화면에는 공급처 정보, 원가, source URL이 보이면 안 된다.
- 관리자는 상품/옵션/주문에서 공급처를 구분할 수 있어야 한다.

## 자동화 범위
- 가격 동기화.
- 품절/판매 상태 동기화.
- 옵션 추가/상품 생성 후보 판정.
- 발주 엑셀 생성.
- 고객 화면 QA.
