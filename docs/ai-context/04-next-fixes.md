# 다음 수정 우선순위

1. DailyFood 실제 사이트 기준 크롤링을 재점검한다.
2. DailyFood 엑셀/snapshot 기준 판매 판단이 남아 있으면 제거한다.
3. 월억 전체 수집 데이터의 이미지/상세 설명 의존성을 제거하고 판매/가격/옵션 중심으로 정리한다.
4. 축산물과 수산물이 제외되지 않고 올바른 카테고리로 분류되는지 QA한다.
5. 공급처 전체 상품 목록과 hub 상품을 전수 비교한다.
6. 마카다미아, 부사사과, 흑찰옥수수 같은 누락 사례를 포함해 누락 0을 목표로 복구한다.
7. 흑수박, 애플수박 같은 상품군이 variable product 1개와 여러 옵션으로 묶이는지 검증한다.
8. 마진 규칙이 모든 옵션 가격에 정확히 적용되는지 검증한다.
9. 이미지 크롤링/첨부 로직을 제거하거나 비활성화한다.
10. 상세 설명은 텍스트만 수집하도록 한다.
11. n8n 자동화가 새 정책을 따르는지 확인한다.
12. QA 리포트에 축산물·수산물 분류, 누락 상품, 중복 상품군, 마진 오류를 포함한다.
