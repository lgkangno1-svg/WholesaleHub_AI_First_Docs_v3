# 03. Risk and Compliance

이 문서는 법률 자문이 아니라 개발/운영 리스크를 낮추기 위한 실무 기준이다.

## 공급처 데이터 수집 리스크 등급

| 수집 방식 | 리스크 | 설명 |
|---|---:|---|
| 거래처 제공 Google Sheet | 낮음 | 공급처가 직접 업데이트하는 가격표 |
| 거래처 제공 Excel/CSV 링크 | 낮음 | 거래처가 제공한 데이터 처리 |
| 수동 업로드 | 낮음 | 관리자가 받은 파일 업로드 |
| 공개 쇼핑몰 목록 페이지 | 낮음~중간 | 낮은 빈도와 제한 필드 조건 |
| AdminPlus 로그인 수집 | 중간~높음 | 약관상 자동화 리스크 |
| 숨겨진 API 분석 | 높음 | 구현 금지 |
| 자동주문 매크로 | 높음 | AdminPlus는 구현 금지 |

## AdminPlus 운영 기준

AdminPlus 계열은 자동주문을 제외한다. 가격 수집이 필요한 경우에도 하루 1회, 오전 11시에만 실행한다.

## 허용 필드

- 상품명
- 옵션명
- 가격
- 재고 상태
- 상품 URL

## 금지 필드

- 상세페이지 HTML
- 상품 이미지
- 리뷰
- 회원 개인정보
- 숨겨진 API 응답
- 결제/주문 내부 데이터
