# 12. Admin Dashboard

## 목적

관리자가 내부 가격 수집 상태, 상품명 매핑, 최저 공급처, WooCommerce 동기화 상태를 확인한다.

## 화면 목록

### 1. 공급처 현황

- 공급처명
- 수집 방식
- 활성 여부
- 마지막 수집 시각
- 성공/실패 상태
- 다음 실행 예정 시각

### 2. 원본 상품 목록

- 공급처
- 원상품명
- 옵션
- 가격
- 재고
- 수집 시각

### 3. 상품명 매핑 관리

- 원상품명
- AI 정규화 결과
- 신뢰도
- 관리자 승인 상태
- 수정/승인 버튼

### 4. 최저가 내부 결과

- 표준상품명
- 옵션키
- 내부 최저 공급처
- 내부 원가
- WooCommerce 연결 상품

### 5. WooCommerce 동기화 로그

- 상품명
- 변경 전 가격
- 변경 후 가격
- 성공/실패
- 에러 메시지
