# Detail Page AI

24/7 automated Korean ecommerce detail-page generation service.

Start here:

1. `docs/PRD.md` — product and service contract
2. `docs/ARCHITECTURE.md` — implementation boundaries
3. `docs/PROJECT_HANDOFF.md` — current state and next work

Current Phase 1 foundation contains plan contracts, order normalization, typo-risk acknowledgement, automatic upload reference selection, internal prompt routing, customer-over-master priority handling, and unit tests.

The repository is public. The product owner's raw master-prompt text must **not** be committed here. Production loads approved prompts from protected server-side storage/secrets.
